This repository features a complete Register-Transfer Level (RTL) implementation of an Arithmetic Logic Unit (ALU) designed entirely in Verilog. Serving as the computational core of a digital processor, this module is engineered to execute a versatile set of arithmetic and bitwise logical operations. The design emphasizes modular and highly readable hardware description practices, making it an excellent foundational block for integration into larger datapath architectures or custom processor pipelines.

Functionally, the ALU processes input operands based on control select lines (opcodes) to perform standard arithmetic computations—such as addition, subtraction via two's complement logic, and increment/decrement operations—alongside essential logical manipulations, including AND, OR, XOR, and bit shifts. A key feature of the design is its robust status evaluation logic, which accurately drives condition flags. These flags real-time signal critical output states, including Carry (overflow beyond the Most Significant Bit), Zero (when the entire result is null), Negative (tracking the sign bit), and Overflow (for signed arithmetic discrepancies).

To ensure functional correctness and reliability, the repository is structured to support straightforward verification. The source code cleanly separates core design modules from simulation testbenches, allowing users to easily compile and verify the logic using standard HDL simulators such as ModelSim, Xilinx Vivado, or Icarus Verilog. By applying varied input vectors and observing the resulting waveforms, developers can confirm the precise execution of opcodes and the accurate assertion of status flags across all edge cases.
